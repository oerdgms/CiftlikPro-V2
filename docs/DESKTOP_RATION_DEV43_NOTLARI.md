# Desktop Rasyon DEV4.3

Bu geliştirme yalnızca masaüstü görünümüdür. Solver hesabı DEV4.2 FIX ile aynıdır.

Kontrol listesi:
- Yem Havuzu daha kompakt.
- Hedef kartları mevcut davranışını korur.
- Rasyon çalışma masasının üstünde 6 hücreli hızlı özet vardır.
- Tablo başlığı ve yem adı sütunu uzun listelerde görünür kalır.
- Değişiklikleri Kaydet çubuğu ekranın altında erişilebilir kalır.
- Akıllı Dengeleme daha kompakt 3 kolon görünür.
- 900 px altı mobil kurallar değiştirilmemiştir.
