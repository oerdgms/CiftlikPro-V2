# MobileAPI6 — Sağlık Yazma

- MobileAPI5 sürü/padok eşitliği korunur.
- Planlı görevlerde `Uygulandı` ikinci kez tetiklenemez.
- Hayvan/buzağı detayından `+ Sağlık Kaydı` eklenebilir.
- Türler: Aşı, İlaç, Hastalık / Muayene.
- Uygulama tarihi, sonraki tarih, maliyet ve not desteklenir.
- Maliyet > 0 ise mevcut finans tablosuna gider kaydı oluşturulur.
- Kayıt doğrudan ortak `health` tablosuna yazılır; masaüstü ve mobil aynı kaydı görür.
