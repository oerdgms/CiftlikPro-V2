# Mobile API V16 — Arşiv, Doğum ve Fotoğraf Önizleme

- Hayvan listesi fotoğraflarına dokununca uygulama içi büyük önizleme açılır.
- Satılan, Kesilen ve Ölen/Kayıp hayvanlar mobil arşiv ekranına taşındı; canlı arama ve kompakt fotoğraflı görünüm kullanılır.
- Gebe dişi kartından Doğum Kaydı açılır; buzağı oluşturulur, anne padoku devralınır ve annenin son aktif gebelik kaydı `Doğum` olarak kapanır.
- API15 masaüstü hayvan kayıt, alış/finans, ırk, fotoğraf ve maliyet işlevleri korunur.
