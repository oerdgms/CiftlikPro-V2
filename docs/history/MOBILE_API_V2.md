# ÇiftlikPro Mobile API2 — Telefon Prototipi

MobileAPI1 salt-okunur API korunur. Bu aşamada `/mobile` altında aynı API'yi kullanan telefon uyumlu prototip eklendi.

## Deneme
1. PC'de ÇiftlikPro'yu kaynaktan çalıştırın.
2. Telefon aynı ağdayken `http://10.0.0.60:8953/mobile` adresini açın.
3. ÇiftlikPro kullanıcı adı/şifresiyle giriş yapın.

## Ekranlar
- Giriş ve 30 günlük token oturumu
- Mobil ana sayfa: aktif hayvan, bugünün işi, aktif padok, gebe sayısı
- Hayvan arama/listesi ve hayvan detayı
- Bugün / geciken / yaklaşan görev filtreleri
- Padok listesi ve hayvan sayıları
- Oturum kapatma

Bu aşama hâlâ salt okunurdur. Veri yazma, çevrimdışı kuyruk ve uygulama mağazası paketi henüz açılmadı.
