# Mobile API V15 — Masaüstü Hayvan Kayıt Sistemi

- Dişi / Erkek / Buzağı yeni kayıt ve düzenleme ekranları masaüstü kayıt mantığına yaklaştırıldı.
- TR sabit küpe ön eki ve mevcut numaranın düzenlemede dolması.
- Irk listesi masaüstü verisinden (animals + calves distinct breed) gelir.
- Alış tarihi, alış fiyatı, ödeme yöntemi, vadeli ise vade tarihi.
- Finansa dahil et seçeneği: Hayvan Alımı giderini oluşturur/günceller; kapatılırsa bağlı alış gideri kaldırılır.
- Buzağıda anne/baba alanları, fotoğraf/kamera ve padok korunur.
