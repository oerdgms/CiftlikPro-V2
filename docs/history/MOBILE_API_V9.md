# ÇiftlikPro MobileAPI9 — Hızlı Saha İşlemleri

MobileAPI8 üzerine saha kullanımını hızlandıran arayüz turudur.

- Gebe dişide yeni tohumlama varsayılanı kaldırıldı; doğrudan **Gebelik Sonucu / Düzenle** açılır.
- Gebe hayvana yeni tohumlama backend koruması aynen korunur.
- Üreme, not ve sağlık eylemleri daha kompakt hale getirildi.
- Sağlık geçmişi satırları detay eylemine hazır hale getirildi.
- Hayvan detayına geçişte sayfanın üst konuma alınması korunur.
- Padok nüfusu, toplu sağlık, görev tamamlama ve 46 aktif sürü mantığı MobileAPI8'den korunur.

Not: Sağlık kaydı düzenle/sil veri mutasyonu bu sürümde bilerek açılmadı; güvenli kayıt kimliği ve regresyon testiyle sonraki turda eklenmelidir.
