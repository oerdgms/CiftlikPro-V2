ÇİFTLİKPRO V2.0 — PYTHON GEREKTİRMEYEN WINDOWS KURULUMU
=======================================================

Bu pakette .BAT dosyası yoktur. Derleme GitHub'ın Windows bilgisayarında yapılır.

1. GitHub.com üzerinde ücretsiz hesap açın veya giriş yapın.
2. Sağ üstteki + düğmesinden "New repository" seçin.
3. Repository adı olarak CiftlikPro-V2 yazın ve "Create repository" deyin.
4. Açılan sayfada "uploading an existing file" bağlantısına tıklayın.
5. Bu ZIP dosyasını önce bilgisayarınızda bir klasöre çıkarın.
6. Çıkan klasörün İÇİNDEKİ bütün dosya ve klasörleri GitHub yükleme ekranına sürükleyin.
   Önemli: .github klasörü de yüklenmelidir.
7. "Commit changes" düğmesine basın.
8. Repository içinde üst menüden "Actions" bölümünü açın.
9. Solda "CiftlikPro Windows Kurulum" iş akışını seçin.
10. "Run workflow" > yeşil "Run workflow" düğmesine basın.
11. Yaklaşık 3–8 dakika bekleyin.
12. Tamamlanan çalışmaya girin.
13. Sayfanın altındaki "Artifacts" bölümünden:
       CiftlikPro-Windows-Setup
    dosyasını indirin.
14. İndirilen ZIP içinden CiftlikPro_Setup.exe dosyasını çıkarın.
15. CiftlikPro_Setup.exe dosyasına çift tıklayıp kurun.

SON KULLANICI BİLGİSAYARINDA:
- Python gerekmez.
- CMD penceresi açılmaz.
- Masaüstü kısayolu oluşur.
- Uygulama tarayıcıyı otomatik açar.
- Veriler şu klasörde korunur:
  %LOCALAPPDATA%\CiftlikPro

ÖNEMLİ GÜVENLİK NOTU:
Dijital kod imzası satın alınmadığı sürece Windows veya bazı antivirüsler,
yeni ve az kullanılan kurulum dosyalarında "bilinmeyen yayıncı" uyarısı gösterebilir.
Bu durum kod imzası olmamasından kaynaklanabilir. Ticari dağıtımda bir kod imzalama
sertifikasıyla CiftlikPro_Setup.exe imzalanmalıdır.
