# Mobile API V7 — Saha Akışı / Scroll Hotfix

- Hayvan detayına geçişte liste scroll konumu artık detay ekranına taşınmaz; detay daima üstten açılır.
- Padok detayına geçişte ekran daima üstten açılır.
- Alt menü ile ana ekran/Hayvanlar/İşler/Padoklar geçişlerinde yeni görünüm üstten başlar.
- Sağlık kayıt formu açılırken ekran üst konuma alınır.
- iOS Safari için tek `scrollTo` yerine ilk render sonrası ikinci güvenli üst-konum senkronu eklendi.
- MobileAPI6 sağlık yazma, 46 aktif sürü hesabı ve padok eşitliği korunmuştur.
