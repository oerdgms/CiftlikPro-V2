# Mobile API V13 — Kompakt Sürü + Hızlı Filtre

- Hayvan görünümü için ortak kompakt kart standardı eklendi.
- Padok içindeki hayvanlar artık fotoğraflı kompakt kartlarla gösterilir.
- Yetişkin ve buzağı fotoğrafları padok API yanıtına eklendi.
- Hayvanlar ekranına masaüstündeki günlük kullanım mantığına uygun Tümü / Dişi / Erkek / Buzağı / Gebe hızlı filtreleri eklendi.
- Arama, fotoğraf, gebe rozeti, padok toplu sağlık, maliyet ve kayıt akışları korunur.
